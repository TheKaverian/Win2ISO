
# Win2ISO

Win2ISO is an application that runs in CMD prompt on Windows. It helps you download Windows ISOs, links are sourced from https://archive.org.



## Features

- Shows a download metre showing the exact percentage of your download
- Has every version of Windows Vista to 11 catalogued.
- Available in both .EXE format and .BAT format
- Uses Powershell to call for GUI.
- Intuitive and thought for the Power-User

## Prerequisites
In order to work, these applications are **required** for Win2ISO to work.

- [cURL](https://curl.se/)
- [Powershell](https://github.com/PowerShell/PowerShell)
- and of course, a stable internet connection.
